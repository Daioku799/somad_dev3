状態: 構成承認後に作成した草稿。発表者本人の説明確認前。

## 発表の中心メッセージ

> 固定した解析条件の範囲では、TSV密度マップを入力とするPOD–RBF ROMが未知配置の最高温度を約0.1 Kの誤差で予測し、FVMで検証すべき低温配置候補の選別に利用できた。

## ストーリー

1. TSV配置は熱設計に効くが、候補が多くFVMだけでは広く探索しにくい。
2. 配置を4×4密度マップにし、POD–RBF ROMで温度場を予測する。
3. ROM構築・選定と分離した未知配置で予測精度を確認する。
4. ROMで候補を選び、最後はFVMで再計算する。
5. 未知配置のTmax MAEは0.0950 K、選んだ候補はFVMでも一様配置より1.119〜1.376 K低温だった。
6. 結論は固定条件での候補選別まで。大域最適性や条件外への一般化は今後の課題である。
