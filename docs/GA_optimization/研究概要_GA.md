# 研究概要・方針：FVM/POD-ROMに基づく3D-IC TSV熱設計最適化

作成日：2026-06-12

## 1. 研究の位置づけ

本研究は、大屋氏の卒論で構築された3D-IC熱解析システムを基盤として、実用径TSVを考慮した熱設計最適化へ発展させるものである。

卒論では、3D-IC内部の熱分布を有限体積法（FVM）で解析し、その計算結果をPOD-ROMにより高速近似する枠組みが整理された。本研究では、この流れをそのまま引き継ぎ、TSV配置を最適化対象として扱えるように、TSV配置表現、FVMスナップショット生成、POD-ROM構築、GA最適化までを一つのワークフローとして整理する。

本研究の基本的な流れは以下である。

```text
TSV配置を低次元パラメータとして表現
→ FVMで温度場スナップショットを作成
→ POD-ROMを構築
→ GAでTSV配置パラメータを最適化
→ 上位候補をFVMで検証
→ 得られた配置傾向を熱設計の観点から分析
```

## 2. FVMによる3D-IC熱解析

3D-ICでは、複数のダイを垂直方向に積層するため、内部に熱がこもりやすい。ホットスポットの発生や最大温度の上昇は、性能低下や信頼性低下につながる。

この熱問題に対し、卒論ではFVMを用いて3D-IC内部の温度場を解析した。FVMでは、解析領域をコントロールボリュームに分割し、各セルに対してエネルギー保存則を適用する。材料物性、熱源分布、境界条件、層構造を反映した温度場を得ることができる。

本研究でも、FVMを基準となる詳細解析手法として用いる。FVMは以下の役割を担う。

- ROM構築用の温度場スナップショットを生成する。
- ROMの精度検証に用いる。
- GA最適化で得られた上位候補を詳細評価する。

## 3. POD-ROMによる高速熱評価

FVMは高精度である一方、最適化ループ内で多数回実行するには計算コストが大きい。そのため、卒論ではPOD-ROMによる高速化が導入された。

POD-ROMでは、複数のFVM解析結果を温度場スナップショットとして集め、スナップショット行列に対してSVDを行う。これにより、温度場を少数のPOD基底の線形結合として近似する。

```text
T(μ) ≈ Φ a(μ)
```

ここで、`μ` は設計パラメータ、`Φ` はPOD基底、`a(μ)` はPOD係数である。

未知の設計パラメータに対しては、RBFなどの補間によりPOD係数を予測し、温度場を再構成する。

```text
μ → a(μ) → T_ROM(μ)
```

本研究では、このPOD-ROMをGA最適化中の高速評価器として用いる。

## 4. TSV配置表現の必要性

実用径TSVを多数扱う場合、個別TSV座標をそのまま設計パラメータにすると、GAとROMの両方で扱いにくくなる。

`N` 本のTSVを個別座標で表すと、少なくとも `2N` 個の座標変数が必要になる。

```text
N本のTSV → 2N個の座標変数
```

例えば500本のTSVでは、座標だけで1000次元になる。このような高次元パラメータは、GAの探索空間を拡大させるだけでなく、POD係数補間のためのROMパラメータとしても不適切である。

したがって、本研究ではTSV配置を個別座標ではなく、低次元なマクロ表現として扱う。

検討した代表的な表現は以下である。

- TSVファーム化
- TSV密度マップ化

## 5. TSVファーム化

TSVファーム化では、複数本のTSVを小規模クラスタとしてまとめ、ファーム単位で配置を扱う。

例：

```text
4×4 TSVファーム
2×8 TSVファーム
line型ファーム
```

GAが扱うパラメータは、ファーム中心座標、形状、回転角、ピッチ、ファーム数などである。

ファーム化の利点は、実TSV座標へ展開しやすく、FVM入力を作りやすい点である。一方で、ファーム形状に表現力が依存し、細かい密度分布や複雑な熱流路を表現しにくい可能性がある。

本研究では、ファーム化を有力な候補として整理しつつ、ROM入力との相性を重視して、初期実装では密度マップ化を中心に進める。

## 6. TSV密度マップ化

TSV密度マップ化では、チップ平面を `Gx × Gy` のグリッドに分割し、各セルにTSV密度を割り当てる。

例：

```text
4×4 密度マップ
8×8 密度マップ
```

各セルの密度をベクトル化し、ROMおよびGAの設計パラメータとして扱う。

例：`4×4` 密度マップの場合、

```text
μ = [ρ_11, ρ_12, ..., ρ_44]
```

となり、16次元のパラメータになる。

密度マップ化の利点は以下である。

- 個別TSV座標より大幅に低次元である。
- ROM入力として扱いやすい。
- GAの個体として扱いやすい。
- TSV群を等価熱伝導率へ変換しやすい。
- マクロな配置傾向を分析しやすい。

以上の理由から、本研究の初期実装では案BであるTSV密度マップ化を採用する。

## 7. 密度マップの制約条件

密度マップには、物理的・設計的な制約を設ける。

主な制約は以下である。

- 各セル密度の上限
- 総TSV密度または総TSV本数の固定
- 配置禁止領域がある場合は該当セル密度を0にする
- 材料・プロセス上のTSV径やピッチの制限

初期実装では、総TSV密度を固定する方針とする。これにより、温度低下がTSV量の増加によるものではなく、配置分布の違いによるものとして解釈しやすくなる。

## 8. 密度マップのサンプリング

POD-ROMを構築するには、複数の密度マップサンプルと、それに対応するFVM温度場が必要である。

サンプリング方法として以下を用いる。

- ランダムサンプリング
- ラテン超方格サンプリング
- 代表的な物理パターンを含むサンプリング

代表的な物理パターンとしては、以下が考えられる。

- 均一密度
- 中央集中
- 外周集中
- ホットスポット近傍集中
- 片側集中
- 対角分布
- 熱源間ブリッジ状分布

完全ランダムだけでは、最適化で現れやすい重要な密度分布を十分に学習できない可能性がある。そのため、ランダム性と物理的代表パターンを組み合わせてスナップショットを作成する。

## 9. 密度マップからFVM入力への変換

密度マップをFVMへ入力する方法は主に2つある。

### 9.1 実TSV座標へ展開する方式

密度マップから各セル内のTSV本数を決め、セル内に規則配置または確率配置する。

```text
密度マップ
→ 各セルのTSV本数
→ 実TSV座標
→ FVM
```

この方式は実配置に近いが、セル内配置ルールに結果が依存する。また、同じ密度でも配置の仕方によって温度場が変わる可能性がある。

### 9.2 等価熱伝導率へ変換する方式

密度マップから各セルのTSV体積率を求め、等価熱伝導率へ変換する。

簡易には以下のように表せる。

```text
k_eff,ij = (1 - φ_ij) k_Si + φ_ij k_Cu
```

ここで、`φ_ij` はセル内のTSV金属体積率、`k_Si` はシリコン熱伝導率、`k_Cu` は銅の熱伝導率である。

この方式では、TSV群を個別形状ではなく材料物性の変化として扱う。

初期実装では、以下の理由から等価熱伝導率方式を採用する。

- ROM入力とFVM入力の対応が明確である。
- 実TSV座標生成の複雑さを避けられる。
- 密度マップ型ROMの有効性を検証しやすい。
- FVMスナップショット生成が比較的容易である。

将来的には、最終候補について実TSV座標へ展開し、詳細FVMで検証する。

## 10. FVMスナップショット生成

各密度マップサンプル `μ_s` に対して、等価熱伝導率マップを作成し、FVMを実行する。

```text
μ_s → k_eff map → FVM → T_s
```

得られた温度場 `T_s` をベクトルとして保存する。

スナップショット行列は以下のように作る。

```text
X = [T_1, T_2, ..., T_S]
```

ここで、`S` はスナップショット数である。

## 11. POD-ROM構築

スナップショット行列 `X` に対してSVDを行う。

```text
X = U Σ V^T
```

左特異ベクトルからPOD基底を選択する。

```text
Φ = [φ_1, φ_2, ..., φ_r]
```

ランク `r` は累積寄与率（RIC）に基づいて決定する。

例：

```text
RIC(r) >= 0.999
```

各スナップショットをPOD基底へ射影し、POD係数を得る。

```text
a_s = Φ^T T_s
```

これにより、密度マップ `μ_s` とPOD係数 `a_s` の対応データが得られる。

未知の密度マップ `μ*` に対しては、RBF補間によりPOD係数を予測する。

```text
μ* → a(μ*)
```

そして、温度場を再構成する。

```text
T_ROM(μ*) = Φ a(μ*)
```

## 12. ROM精度評価

ROM構築後、検証用密度マップに対してFVMとROMを比較する。

評価指標は以下である。

- 温度場全体の相対誤差
- 最大温度誤差
- 最大温度差の誤差
- ホットスポット位置の一致
- FVM評価時間とROM評価時間の比較
- スナップショット数に対する精度変化

最大温度誤差は以下のように評価する。

```text
error_Tmax = |Tmax_FVM - Tmax_ROM|
```

ROM精度が不十分な場合は、スナップショット追加、密度マップ解像度の調整、サンプリング方法、補間手法を見直す。

## 13. GAによる密度マップ最適化

ROM構築後、GAにより密度マップを最適化する。

GA個体は密度マップである。

```text
個体 = [ρ_11, ρ_12, ..., ρ_GxGy]
```

初期段階の目的関数は最大温度 `Tmax` とする。

```text
minimize Tmax
```

総TSV密度は目的関数ではなく制約として扱う。

```text
Σρ_ij = constant
```

または、

```text
Σρ_ij <= ρ_total,max
```

とする。

GAで得られた密度分布について、熱源・ホットスポット・外周との関係を分析し、どのような物理的特徴が最適化結果として現れるかを確認する。

## 14. 目的関数と制約の扱い

当初、温度と配線長の多目的最適化も検討した。多くの3D-IC/TSV配置最適化では、最大温度とHPWLなどの配線長がトレードオフとして扱われる。

しかし、現在のモデルでは、ネットリスト、ピン座標、信号TSV、RDL接続点を持たない。そのため、厳密なHPWLは計算できない。

また、現在のモデルでは発熱領域を連続的な熱源密度として扱っており、個別トランジスタ座標を持たない。そのため、厳密なKOZ判定も現時点では不要である。

現段階で扱う目的関数と制約は以下とする。

```text
目的関数：Tmax または ΔT
制約：総TSV密度、各セル密度上限、材料・幾何条件
```

将来的に、信号TSV、ブロック配置、ネットリストを導入した段階で、HPWL、配線混雑、KOZを拡張項目として扱う。

## 15. TT分解の位置づけ

POD-ROMでは、ROM入力の次元を抑えるために低解像度密度マップを使う。しかし、低解像度化すると、局所的なTSV密度分布やファーム内部構造が失われる可能性がある。

この問題への発展案として、TT分解を用いた高解像度ROMを検討する。

```text
POD-ROM：4×4 などの低解像度密度マップ
TT-ROM：16×16 や 32×32 の高解像度密度マップ
```

TT分解により、高解像度の密度場を低ランク構造として圧縮できれば、POD-ROMで生じる粗視化誤差を軽減できる可能性がある。

ただし、TT分解は初期実装では主題を複雑にするため、まずはPOD-ROMを構築し、その限界が見えた段階で導入を検討する。

## 17. 推奨する初期設定

初期実装では以下の条件を推奨する。

```text
TSV表現：密度マップ
密度グリッド：4×4
総TSV密度：固定
FVM入力：等価熱伝導率マップ
ROM：POD + RBF
目的関数：Tmax
HPWL：扱わない
KOZ：扱わない
シリコン熱伝導率：定数
RDL：等価熱伝導率
```

この設定で、まずは密度マップ型POD-ROMがFVM温度場をどの程度再現できるかを確認する。

## 18. 今後のロードマップ

### Step 1：密度マップ生成とFVM接続

- `4×4` 密度マップを実装する。
- 密度マップから等価熱伝導率マップを生成する。
- FVMで温度場を計算できるようにする。

### Step 2：POD-ROM構築

- 複数密度マップでFVMスナップショットを収集する。
- POD基底を作る。
- RBF補間によりROMを構築する。
- FVMとの誤差を評価する。

### Step 3：GA最適化

- 密度マップを個体としてGAを実装する。
- ROMで `Tmax` を高速評価する。
- 上位候補をFVMで検証する。

### Step 4：物理的特徴の分析

- 最適化後の密度分布を分析する。
- ホットスポット近傍、外周、熱源間などへの密度集中傾向を見る。
- 物理的特徴が最適化結果としてどのように現れるかを確認する。

### Step 5：発展

- `8×8` 密度マップへの高解像度化
- 実TSV座標への展開と詳細FVM検証
- TT-ROMによる高解像度密度場の扱い
- 多目的最適化
- HPWLや信号TSVモデルの導入

## 19. まとめ

本研究は、大屋氏卒論で構築されたFVM/POD-ROMの流れを引き継ぎ、実用径TSVを考慮した熱設計最適化へ拡張する。

TSVを個別座標として扱うと、GA探索とROM構築の両方で高次元化が問題となる。そのため、初期実装ではTSV配置を密度マップとして表現し、等価熱伝導率マップへ変換してFVMスナップショットを作成する。

得られた温度場からPOD-ROMを構築し、GAによって密度マップを最適化する。物理的特徴は事前に埋め込むのではなく、最適化結果として現れる密度分布や温度場から分析する。

将来的には、密度マップの高解像度化、TT-ROM、実TSV座標への展開、配線長や信号TSVを含む多目的最適化へ発展させる。
