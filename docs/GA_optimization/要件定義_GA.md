# 3D-IC熱性能最適化プログラム 要件定義

## 1. 前提

- 対象論文: 「3D-ICの熱性能最適化における次元低減手法とパラメータ探索手法の研究」
- 有限体積法（FVM）などの熱解析ソルバ本体を利用する。
- 本要件では、ソルバの周辺機能である入力生成、解析モデル構築、ROM構築、最適化制御、結果出力を対象とする。

## 2. 目的

3D-ICの熱設計において、設計者が与える制約条件に基づき、層厚、TSV配置、TSV寸法などの設計パラメータを高速に探索し、チップ全体の最高温度を小さくする設計案を出力する。

## 3. 入力要件

### 3.0 単位系・座標系

現行実装に合わせ、入力値と内部計算ではSI単位系を使用する。

- 長さは `m` とする。
  - 例：`10 µm = 10e-6 m`
  - 例：`1.2 mm = 1.2e-3 m`
- 温度は `K` とする。
- 熱伝導率は `W/(m K)` とする。
- 密度は `kg/m^3` とする。
- 比熱は `J/(kg K)` とする。
- 体積発熱率は `W/m^3` とする。
- 熱伝達率は `W/(m^2 K)` とする。
- 座標原点はチップ平面左下かつ積層構造の下面を `(x, y, z) = (0, 0, 0)` とする。
- x方向の範囲は `0 <= x <= lx`、y方向の範囲は `0 <= y <= ly` とする。
- 既定のチップ寸法は現行実装に合わせて `lx = ly = 1.2e-3 m` とする。
- z方向は下から上へ積層する向きとする。
- 現行実装の既定格子は `NX = 240`, `NY = 240`, `NZ = 30` とし、x-y方向の格子幅は `dx = lx / NX`, `dy = ly / NY` とする。

### 3.1 GDSII入力

- GDSIIファイルを読み込めること。
- シリコン層、熱源、Power Gridなどの平面形状を取得できること。
- レイヤごとのポリゴン形状を扱えること。

### 3.2 JSON設定入力

JSON設定ファイルから以下を読み込めること。

- チップ寸法
- 各層の厚さ
- 材料物性値
  - 熱伝導率
  - 密度
  - 比熱
- TSVの設定
  - 座標
  - 半径
  - 個数
  - 配置可能範囲
  - 最小ピッチ
  - セル内配置方式
- はんだバンプ、Underfill、PCB、ヒートシンクなどの構造情報
- 熱源条件
  - 発熱量
  - 熱源位置
  - 熱源温度
- 境界条件
- 最適化対象パラメータ
- 各パラメータの探索範囲
- GA、ROM、FVM検証の設定値

密度マップ方式では、個別TSV座標は必須入力とせず、密度マップまたは密度マップ生成条件を入力する。

### 3.3 TSV密度マップ設定入力

初期実装では、GAやROMの設計パラメータをTSV密度マップとして扱い、FVM実行時には密度マップから実TSV座標へ展開する。JSON設定ファイルから以下を読み込めること。

- 密度マップ方式を使用するかどうか
  - 例：`tsv_mode = "density"`
- 密度グリッド分割数
  - 例：`4×4`, `8×8`
- 各セル密度の定義方法
  - TSV本数密度
  - セル内最大配置可能本数に対する割合
- 総TSV本数の上限
- 各セルの密度上限
- 密度固定セルまたは配置禁止セル
- TSV半径または直径
- TSV最小ピッチ
- TSV端部マージン
- TSV高さまたは貫通対象層
- 密度マップから実TSV座標へ展開する配置規則
  - セル内格子配置
  - セル内中央寄せ格子配置
  - セル内ランダム配置
- 密度マップのサンプリング方法
  - ランダムサンプリング
  - ラテン超方格サンプリング
  - 代表パターンサンプリング

### 3.4 初期実装で扱わない入力

現在の熱解析モデルでは、発熱領域を連続的な熱源密度として扱い、個別トランジスタ座標、ネットリスト、ピン座標、信号TSVを持たない。そのため、初期実装では以下を必須入力としない。

- HPWL計算用ネットリスト
- 信号ピン座標
- 信号TSV接続情報
- 個別トランジスタ座標
- 厳密なKOZ形状

これらは、信号TSVやブロック配置を扱う段階で拡張入力とする。

## 4. モデル生成要件

### 4.1 プリミティブ表現

形状はプリミティブ表現で扱う。

- 直方体
- 円柱
- ポリゴン

各プリミティブは以下の情報を持つ。

- 形状タイプ
- 座標
- サイズ
- 材料
- 部品種別

### 4.2 ハイブリッドモデル構築

JSONとGDSIIを併用して解析モデルを構築する。

- JSONで扱う情報
  - TSV
  - 層厚
  - 材料
  - 境界条件
  - 探索対象パラメータ
- GDSIIで扱う情報
  - チップ形状
  - 熱源形状
  - Power Gridなどの平面レイアウト

### 4.3 格子生成

- 3D計算格子を生成できること。
- 各格子セルに対応する部品・材料を一意に割り当てること。
- x-y方向は均一格子または指定分割に対応すること。
- z方向は層境界付近を考慮した不均一格子に対応すること。
- 格子生成後、未割当セルがないことを検証すること。

### 4.4 GDSIIポリゴンと格子の対応付け

- Ray Casting法により、格子セルとGDSIIポリゴンの包含関係を判定すること。
- セル中心点による判定に対応すること。
- 必要に応じてサブサンプリングによる判定に対応すること。
- サブサンプリングを用いる場合、セル内の一定割合以上が図形内なら対象部品に割り当てること。

### 4.5 モデル妥当性検証

以下を検証すること。

- TSVがチップ外に出ていないこと。
- TSV同士が干渉しないこと。
- TSV中心間距離が最小ピッチ以上であること。
- TSVが配置禁止領域に置かれていないこと。
- 層厚が正であること。
- 必須材料値が欠けていないこと。
- 熱源が有効な領域に配置されていること。
- 格子セルが未割当になっていないこと。

### 4.6 TSV密度マップ生成

密度マップ方式を使用する場合、以下を満たすこと。

- チップ平面を `Gx × Gy` の密度セルに分割できること。
- 各密度セルにTSV配置密度 `rho_ij` を割り当てられること。
- 密度マップをROM用パラメータベクトルへ変換できること。

```text
mu = [rho_11, rho_12, ..., rho_GxGy]
```

- `rho_ij` は、各セルにおける最大配置可能TSV本数に対する割合として扱うこと。
- 各セルの実TSV本数 `n_ij` は、セルごとの最大配置可能本数 `n_max,ij` から計算できること。

```text
n_ij = round(rho_ij * n_max,ij)
```

- `rho_ij` は以下の範囲に制約すること。

```text
0 <= rho_ij <= rho_cell_max
```

- 初期値として `rho_cell_max = 1.0` とする。
- 総密度は固定せず、総TSV本数に不等式制約を与えること。

```text
N_total = sum(n_ij)
N_min <= N_total <= N_max
```

- 初期実装では `N_min = 0` とし、`N_max` は最小ピッチとチップ面積から決まる全体配置可能本数以下に設定すること。
- 各セルの密度上限を適用できること。
- 配置禁止セルの密度を0にできること。
- 生成された密度マップが制約を満たすか検証できること。

初期実装では、密度グリッドは `4×4` を既定値とする。

### 4.7 密度マップから実TSV座標への変換

初期実装では、密度マップを実TSV座標へ展開してFVMへ渡す。等価熱伝導率マップ方式は初期実装の対象外とする。

- 密度セルの寸法を以下で定義すること。

```text
w_cell = lx / Gx
h_cell = ly / Gy
```

- TSV半径を `r_tsv`、直径を `d_tsv = 2 * r_tsv`、最小ピッチを `p_min` とすること。
- セル内端部マージンを `m_edge` とし、初期値は `m_edge = max(r_tsv, p_min / 2)` とすること。
- 各セル内の最大配置可能本数は、保守的に矩形格子配置で見積もること。

```text
n_x,ij = max(0, floor((w_cell - 2 * m_edge) / p_min) + 1)
n_y,ij = max(0, floor((h_cell - 2 * m_edge) / p_min) + 1)
n_max,ij = n_x,ij * n_y,ij
```

- `n_ij` 本のTSVを、セル内の候補格子点から選択して実座標へ展開できること。
- 初期実装では、セル中心に近い候補点から順に選ぶ中央寄せ格子配置を既定方式とする。
- 展開後の全TSVについて、以下の制約を満たすこと。

```text
r_tsv <= x <= lx - r_tsv
r_tsv <= y <= ly - r_tsv
distance((x_a, y_a), (x_b, y_b)) >= p_min
```

- 展開後のTSV座標は、FVMの既存TSV円柱モデルへ渡せる形式に変換すること。
- 密度マップ `mu`、各セルTSV本数 `n_ij`、展開後TSV座標の対応を保存すること。

### 4.8 TSV寸法・製造制約

TSV寸法と配置制約は、現行実装の単位系と文献調査に基づき、以下を初期値とする。

- TSV直径の既定値は `d_tsv = 10e-6 m` とする。
- TSV直径の探索範囲は `5e-6 m <= d_tsv <= 20e-6 m` とする。
- TSV半径は `r_tsv = d_tsv / 2` とする。
- TSV最小ピッチの既定値は `p_min = 30e-6 m` とする。
- TSV高さの既定値は、現行実装に合わせて `h_tsv = 100e-6 m` とする。
- TSVアスペクト比は以下で定義する。

```text
AR = h_tsv / d_tsv
```

- 初期実装では、アスペクト比制約を以下とする。

```text
5 <= AR <= 20
```

- `h_tsv = 100e-6 m`, `d_tsv = 10e-6 m` の場合、`AR = 10` となる。
- TSV材料は銅を既定とし、熱伝導率は現行実装の材料値 `386 W/(m K)` を用いる。
- シリコン熱伝導率は、現行実装では `149 W/(m K)` を用いる。ただし、線形ROM検証時は研究方針に応じて `100 W/(m K)` へ固定する設定を持てるようにする。
- TSVの絶縁膜、バリアメタル、ライナー厚さは初期実装では明示的にモデル化せず、銅円柱として扱う。
- KOZは初期実装では厳密評価しない。ただし、将来拡張に備えてKOZ半径を入力できる設計にする。

### 4.9 実TSV座標展開への将来拡張

将来的な詳細検証のため、セル内配置規則を拡張できる余地を残すこと。

- セル内ランダム配置に対応できること。
- セル内Poisson disk配置に対応できること。
- 熱源近傍へ優先的に配置するヒューリスティックに対応できること。
- KOZ半径を考慮した配置に対応できること。

## 5. ソルバ連携要件

FVMソルバを外部モジュールとして呼び出す。

### 5.1 ソルバ入力

ソルバへ以下を渡せること。

- 格子情報
- 各セルの材料物性値
- 熱源分布
- 境界条件
- 設計パラメータ
- TSV密度マップから生成された実TSV座標
- 密度マップサンプルID
- ROM構築用パラメータベクトル `mu`

### 5.1.1 解析環境・境界条件

初期実装では、現行実装の解析条件を既定値として用いる。

- 解析は定常解析を既定とする。
  - `is_steady = true`
- 既定ソルバは `pbicgstab` とする。
- 既定前処理・スムーザは `gs` とする。
- 既定実行モードは `sequential` とする。
- 既定収束許容値は `epsilon = 1.0e-4` とする。
- 線形ソルバの最大反復数は `20000` を既定値とする。
- 初期温度は `300 K` とする。
- 疑似時間刻みは現行実装に合わせて `Δt = 10000.0` とする。
- 境界条件は以下を既定値とする。

```text
x_minus: convection, h = 5.0 W/(m^2 K), T_amb = 300 K
x_plus : convection, h = 5.0 W/(m^2 K), T_amb = 300 K
y_minus: convection, h = 5.0 W/(m^2 K), T_amb = 300 K
y_plus : convection, h = 5.0 W/(m^2 K), T_amb = 300 K
z_minus: isothermal, T = 300 K
z_plus : convection, h = 5.0 W/(m^2 K), T_amb = 300 K
```

- 体積発熱率の既定値は現行実装に合わせて `Q_src = 1.6e11 W/m^3` とする。
- 境界条件、収束許容値、ソルバ種別、格子数はJSONまたは実行引数で変更できること。

### 5.2 ソルバ出力

ソルバから以下を受け取れること。

- 温度場
- 最高温度
- 温度勾配
- ホットスポット位置
- 計算時間
- 収束情報
- エラー情報
- スナップショット保存用の温度場ベクトル
- 密度マップサンプルIDとの対応情報

## 6. ROM構築要件

### 6.1 オフライン計算

- 複数の設計パラメータ点でソルバを実行し、温度場スナップショットを蓄積すること。
- スナップショット行列を構築すること。
- サンプリング点と温度場を紐づけて保存すること。
- 初期実装では、設計パラメータ点をTSV密度マップとして扱うこと。
- 密度マップを実TSV座標へ展開してからソルバを実行すること。
- 均一密度、中央集中、外周集中、ホットスポット近傍集中、片側集中、対角分布などの代表パターンをスナップショット候補に含められること。

### 6.1.1 密度マップサンプリング

- ランダムサンプリングに対応すること。
- ラテン超方格サンプリングに対応できること。
- 代表パターンサンプリングに対応すること。
- 総TSV本数上限制約を満たすようにサンプルを修正または破棄できること。
- 密度上限制約を満たさないサンプルを修正または破棄できること。

### 6.2 POD基底生成

- スナップショット行列からPOD基底を作成すること。
- SVDにより特異値と基底を取得すること。
- 累積エネルギー寄与率（RIC）に基づき基底数を決定すること。

### 6.3 RBFモデル

- 設計パラメータからモーダル係数を予測するRBFモデルを構築すること。
- ガウスカーネルを使用できること。
- カーネル幅はサンプリング点間距離に基づいて設定できること。
- RBFモデルの入力は、正規化された密度マップベクトル `mu` とすること。
- 密度マップの各セル値を正規化し、距離計算で特定セルが過度に支配しないようにすること。

### 6.4 ROMの保存

以下を保存・再読み込みできること。

- POD基底
- 特異値
- RBF重み
- サンプリング済みパラメータ
- スナップショット情報
- 正規化に使用したパラメータ範囲
- 密度マップのグリッド定義
- 密度マップから実TSV座標への展開条件
- TSV寸法、最小ピッチ、端部マージン
- 総TSV本数制約と各セル密度上限

### 6.5 ROM精度評価

ROM構築後、検証用密度マップに対してFVM結果とROM結果を比較できること。

- 温度場全体の相対誤差を計算できること。
- 最高温度誤差を計算できること。
- 最大温度差の誤差を計算できること。
- ホットスポット位置の一致度を確認できること。
- FVM評価時間とROM評価時間を比較できること。

最高温度誤差は以下で定義する。

```text
error_Tmax = |Tmax_FVM - Tmax_ROM|
```

### 6.6 ROM学習・検証データ分割

ROM構築用のサンプルは、学習用、検証用、テスト用に分割できること。

- 既定の分割比率は以下とする。

```text
training : validation : test = 70 : 15 : 15
```

- 代表パターンは学習用に必ず含めること。
- 検証用・テスト用には、代表パターン以外のランダムまたはラテン超方格サンプルを含めること。
- 分割に用いた乱数シードを保存すること。
- 分割後も、各データ群で密度範囲と総TSV本数範囲が極端に偏らないように確認すること。

### 6.7 ROM精度合格基準

初期実装では、ROMの採用基準を以下とする。

- 検証用データにおける最高温度誤差の平均値が `2 K` 以下であること。
- 検証用データにおける最高温度誤差の最大値が `5 K` 以下であること。
- 温度場全体の相対L2誤差の平均値が `5 %` 以下であること。
- ホットスポット位置ずれが、x-y方向で密度セル1個分以内であること。
- 上記基準を満たさない場合は、スナップショット追加、RBFカーネル幅調整、POD基底数増加のいずれかを行うこと。

文献からPOD + RBF ROMに対する3D-IC熱解析専用の標準的な合格閾値が一意に見つからない場合は、上記を本研究の初期基準として設定し、FVM再検証結果に基づいて調整する。

## 7. オンライン最適化要件

### 7.1 GAによる探索

- GAにより設計パラメータ候補を生成すること。
- 初期実装では、個体はTSV密度マップベクトルとして表現すること。
- 交叉、突然変異、選択を実行できること。
- 制約違反個体は修正または破棄すること。
- 総TSV本数上限制約を満たすように、交叉・突然変異後の個体を修正または破棄できること。
- 各セル密度上限を超えた個体を修正または破棄できること。
- 配置禁止セルがある場合、そのセルの密度を0に維持できること。

### 7.2 ROMによる高速評価

- 各個体をROMで高速評価すること。
- 評価関数は基本的に以下とする。

```text
f(mu) = max T_ROM(x, mu)
```

- 目的はチップ全体の最高温度を最小化すること。
- 初期実装では、評価関数は最高温度 `Tmax` の最小化を基本とすること。
- 必要に応じて最大温度差 `DeltaT` を評価できること。
- TSV本数または総TSV密度は目的関数ではなく、上限制約として扱うこと。

### 7.2.1 現段階で扱わない目的関数

現段階では、HPWLを目的関数に含めないこと。

- 現在のモデルはネットリスト、ピン座標、信号TSVを持たないため、厳密なHPWLを計算できない。
- 熱TSV密度マップを対象とする初期実装では、配線長ではなく最高温度と密度制約を優先する。
- HPWL、配線混雑、信号TSV制約は将来拡張とする。

### 7.3 停止条件

以下の停止条件を設定できること。

- 最大世代数に到達
- 改善量が一定以下
- 一定世代で改善なし
- 目標温度以下

### 7.4 GAパラメータ設定要件

GAに関する以下の設定をJSONから指定できること。

- 個体数
  - 初期値：`population_size = 50`
- 最大世代数
  - 初期値：`max_generations = 100`
- 選択方式
  - 初期値：トーナメント選択
- トーナメントサイズ
  - 初期値：`tournament_size = 3`
- 交叉方式
  - 初期値：一様交叉
- 交叉率
  - 初期値：`crossover_rate = 0.8`
- 突然変異方式
  - 初期値：セル値へのガウス摂動
- 突然変異率
  - 初期値：`mutation_rate = 0.1`
- 突然変異標準偏差
  - 初期値：`mutation_sigma = 0.1`
- エリート保存数
  - 初期値：`elite_count = 2`
- 制約違反時の処理
  - 初期値：修正可能なら修正し、不可能なら破棄

## 8. LLM-GA要件

LLMをGAの補助として利用できる設計にする。ただし、初期実装ではLLMを必須機能としない。物理的特徴を事前にジェノタイプとして埋め込むのではなく、GAとROM評価の結果として現れる密度分布を分析する。

### 8.1 LLMの役割

LLMは以下に関与できること。

- 最適化結果の要約
- 密度分布と温度場の関係の説明
- 実験条件やパラメータ範囲の整理補助
- 異常な個体や制約違反傾向の指摘
- 有望個体の理由説明

### 8.2 LLM出力の検証

LLM出力は必ず検証レイヤを通すこと。

- TSV配置制約
- チップ範囲
- TSV間距離
- 層構造制約
- 数値形式
- JSONスキーマ
- 密度マップ制約
- 総TSV本数上限制約

制約違反がある場合は、自動修正または破棄すること。

## 9. ROM信頼性判定要件

### 9.1 外挿検知

- 新しいパラメータが既存スナップショット範囲から外れているか判定すること。
- 各パラメータを正規化して距離を計算すること。
- 最近傍スナップショットとの距離が閾値 `dcrit` を超えたら外挿と判定すること。
- 密度マップの各セル値が学習時の最小値・最大値範囲から外れた場合も外挿候補とすること。

### 9.2 閾値設定

- `dcrit` は初期スナップショット群の最近傍距離平均の1.5から2.0倍程度を既定値にすること。
- `dcrit` は設定ファイルで変更できること。

### 9.3 外挿時の処理

- 外挿と判定された場合はROMではなくFVMソルバを実行すること。
- 得られた結果をスナップショットに追加すること。
- ROMを更新すること。

## 10. 誤差検証要件

### 10.1 検証対象

以下の個体について、ROM結果をソルバ結果で検証すること。

- 有望個体
- エリート個体
- 各世代の最良個体
- 最終最良個体
- ROM学習範囲外に近い密度マップ個体

### 10.2 誤差指標

最大絶対誤差を計算する。

```text
epsilon_max = max |T_ROM,k - T_FVM,k|
```

### 10.3 ROM更新判定

- `epsilon_max <= epsilon_tol` の場合、ROM結果を信頼する。
- `epsilon_max > epsilon_tol` の場合、ソルバ結果をスナップショットに追加し、ROMを再構築または逐次更新する。

## 11. 出力要件

### 11.1 最適化結果

以下を出力すること。

- 最良設計パラメータ
- 最良密度マップ
- 密度マップから展開したTSV座標
- TSV半径
- TSV個数
- 層厚
- 最高温度
- 温度場データ
- ホットスポット位置
- ROM評価かFVM検証済みか
- 世代ごとの評価履歴
- ROM更新履歴
- 総TSV本数制約の充足状況
- 各セル密度制約の充足状況

### 11.2 可視化用出力

以下を出力できること。

- xy断面温度分布
- yz断面温度分布
- TSV密度マップ図
- 密度マップから展開したTSV座標図

## 12. 非機能要件

- ソルバ本体と最適化制御を分離すること。
- JSON設定だけで探索条件を変更できること。
- 途中停止・再開ができること。
- スナップショット、ROM、GA状態を保存できること。
- LLMを使わない通常GAモードでも動作すること。
- ソルバ実行失敗時は、その個体を無効化しログに残すこと。
- 乱数シードを指定して再現性を確保すること。
- 各処理時間を記録し、ROMによる高速化効果を評価できること。
- 密度マップ、展開後TSV座標、FVM結果、ROM結果の対応関係を追跡できること。
- 初期実装では、個別TSV座標を必須入力にしなくても動作すること。
- 密度マップから実TSV座標へ展開する処理の再現性を確保すること。

### 12.1 ログ・スキーマ・再現性要件

- 入力JSONのスキーマ検証を行うこと。
- 単位系がSI単位であることを前提とし、明らかに桁が異なる値には警告を出すこと。
- 各FVM実行について、設定ファイル、密度マップ、展開後TSV座標、実行引数、収束情報、エラー情報を保存すること。
- 各ROM構築について、スナップショットID、POD基底数、RIC、RBF設定、学習・検証・テスト分割を保存すること。
- 各GA実行について、乱数シード、GAパラメータ、世代ごとの最良値、制約違反数、FVM再検証回数を保存すること。
- 同一設定と同一乱数シードで、同じ密度マップ、同じ展開後TSV座標、同じGA初期集団を再生成できること。

## 15. 初期実装スコープ

密度マップ方式の初期実装では以下を対象とする。

- TSV表現は密度マップ方式とする。
- 密度グリッドは `4×4` を既定値とする。
- 総TSV密度は固定せず、総TSV本数上限の不等式制約として扱う。
- FVM入力は、密度マップから展開した実TSV座標とする。
- ROMはPOD + RBFとする。
- 目的関数は最高温度 `Tmax` とする。
- HPWLと厳密KOZは扱わない。
- LLM-GAは必須機能とせず、通常GAで動作することを優先する。

## 16. 将来拡張スコープ

以下は初期実装後の拡張対象とする。

- `8×8` 以上の高解像度密度マップ
- TT分解を用いた高解像度ROM
- 実TSV座標展開方式の高度化
- TSV絶縁膜、バリアメタル、ライナーを含む詳細FVM検証
- HPWL、配線混雑、信号TSVを含む多目的最適化
- 個別トランジスタ座標を用いたKOZ評価

## 17. 文献・製造制約に基づく初期設定根拠

TSV寸法・配置制約は、以下の文献調査結果と現行実装の格子解像度を踏まえて設定する。

- Chen et al. は、TSVサイズとピッチがマイクロメートル範囲へスケールしていること、密なTSV farmが熱的な影響を持つことを指摘している。
- 同論文では、大きな銅TSVは直径が数十µm、先端的な高密度TSVは数µm径まで小さくなり得ること、3D ICではウェハ厚が `10–100 µm` 程度まで薄化されることが述べられている。
- Rimskog and Bauer は、高密度TSV製造例として、最大 `600 µm` 厚基板に対して `30 µm` ピッチまで対応するTSVプロセスを報告している。
- 現行実装では、チップ寸法 `1.2 mm × 1.2 mm`、既定格子 `240 × 240` であるため、x-y格子幅は `5 µm` となる。したがって、初期TSV直径を `10 µm` とすると、直径が約2格子に相当し、現行格子でも最低限の円柱表現が可能である。
- 現行実装のシリコン層厚は `100 µm` であるため、`d_tsv = 10 µm` ではアスペクト比 `AR = 10` となり、研究用初期値として妥当である。
- 以上より、初期実装では `d_tsv = 10e-6 m`、探索範囲 `5e-6 m <= d_tsv <= 20e-6 m`、最小ピッチ `p_min = 30e-6 m`、アスペクト比制約 `5 <= AR <= 20` を採用する。
- POD + RBF ROMの3D-IC熱解析に対する標準的な合格閾値は、今回の調査範囲では一意に確認できなかった。そのため、初期基準として `Tmax` 平均誤差 `2 K` 以下、最大誤差 `5 K` 以下、温度場相対L2誤差平均 `5 %` 以下を設定し、FVM再検証結果に基づいて見直す。

参考文献:

- Yibo Chen, Eren Kursun, Dave Motschman, Charles Johnson, Yuan Xie, "Through Silicon Via Aware Design Planning for Thermally Efficient 3-D Integrated Circuits", IEEE TCAD, 2013. [arXiv](https://arxiv.org/abs/2508.13160)
- Magnus Rimskog, Tomas Bauer, "High Density Through Silicon Via (TSV)", DTIP 2008. [arXiv](https://arxiv.org/abs/0805.0922)
