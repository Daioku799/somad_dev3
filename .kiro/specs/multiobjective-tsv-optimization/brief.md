# Requirements Document

## Project Description (Input)

3D-IC熱解析の4×4整数TSV密度マップについて、単一の最高温度最小化から、最高温度 `Tmax`、離散セル中心温度勾配最大値 `gmax`、TSV本数を扱う多目的最適化へ拡張する。

主探索は2目的・3目的ともNSGA-IIとする。2目的ではTSV本数を36、48、60へ個別に固定して `Tmax` と `gmax` を最小化する。3目的ではTSV本数を36以上60以下の整数として可変にし、`Tmax`、`gmax`、TSV本数を最小化する。同一評価予算のランダム探索をbaselineとし、両方式の代表点を同一規則でFVM再評価する。

現行基準はTSV直径40 µm、最小中心間ピッチ80 µm、240×240×30格子、4×4密度マップ、密度セル当たり最大9本である。将来検討する10 µmはTSV直径であり、配置ピッチおよび計算格子は本specでは決定しない。

`gmax` はFVMと同じ直列熱抵抗の面コンダクタンスと面熱流束から再構成する離散指標とする。半導体セル（材料ID 2および7）を対象に内部材料界面を含め、ゴーストセルと外部境界依存セルを除外する。連続場の厳密な最大勾配は主張しない。

ROM datasetは、対称Dirichlet混合から生成する通常配置444件と、7規則×3本数の独立stress set 21件で構成する。ROMの有効性は値誤差、FVM設計幅に対する誤差比、本数別Spearman順位相関、配置外挿stress、xy方向二格子感度、および代表候補のFVM再評価で判定する。

出力は3目的の3次元図と3種類の2次元図を含む近似パレート集合として扱い、大域最適性、真のパレートフロントまたは3次元格子独立性を主張しない。本specは多目的探索とそのdataset・目的定義・検証について旧 `paper-rom-pipeline` の該当内容を置き換える。
