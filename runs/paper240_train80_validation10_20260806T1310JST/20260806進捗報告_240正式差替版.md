# ROM性能に影響する5条件の比較実験

<ul class="experiment-index">
  <li><strong>実験1A｜ROM入力解像度</strong>同じTSV配置・温度場を、異なる密度マップ解像度で学習する。</li>
  <li><strong>実験1B｜TSV配置生成解像度</strong>同じ基礎密度分布から解像度別にTSVを再配置し、温度場を比較する。</li>
  <li><strong>実験2｜snapshot数</strong>モデル作成に使う温度場データ数を変え、ROM精度への影響を調べる。</li>
  <li><strong>実験3｜PODモード数</strong>保持する温度場基底数を変え、POD表現とRBF予測の制約を分ける。</li>
  <li><strong>実験4｜RBFパラメータ</strong>Gaussian RBFの ε・λを変え、L2誤差が小さい条件を探す。</li>
</ul>

<p class="conditions">実験1A：旧60×60×30格子／実験1B：探索的240×240×30格子／実験2–4：新240×240×30格子。由来の異なる誤差値は直接比較しない。</p>

<!--
各実験は結果スライド冒頭の「実験」欄で比較方法を説明する。snapshotはFVMで得た温度場データを指す。

# 実験1Aと1Bの違い

| 項目 | 実験1A | 実験1B |
|---|---|---|
| 出発点 | 実際のTSV座標 | 16×16二値パターン |
| 解像度変更 | 座標を密度マップへ集計する解像度 | TSV座標を生成する格子解像度 |
| TSV物理座標 | 同じ | 解像度ごとに変わる |
| FVM温度場 | 同じ | 解像度ごとに再計算 |
| 比較対象 | ROM予測誤差 | 物理配置距離とFVM温度場差 |
| 確認すること | ROM入力表現に必要な解像度 | 配置生成格子を粗くした影響 |

<p class="comparison-summary">実験1Aでは、TSV物理座標・FVM温度場・POD基底を固定し、ROM入力パラメータの解像度だけを変えることで、入力解像度がROM予測精度へ与える影響を調べる。実験1Bでは、同じ基礎密度パターンとTSV総数から解像度ごとに物理配置を再生成し、FVM温度場を再計算することで、配置生成格子の解像度がTSV配置と熱性能へ与える影響を調べる。</p>

<p class="conditions">実験1AのTSV座標は保存case configから再構成。1Aは入力表現、1Bは物理配置生成への影響を評価する。</p>

<!--
1AではケースごとのTSV物理座標とFVM温度場を固定し、入力符号化だけを変える。1Bでは同じ基礎パターンから解像度ごとにTSV座標を再生成し、FVMも再実行する。

# 実験4：RBFパラメータ別の予測誤差

<div class="exp1a-layout">
  <div class="exp1a-panel">
    <img src="slide_figures/experiment_4_l2_heatmap_240.png" alt="240格子のepsilonとlambdaに対する平均L2ノルム誤差のヒートマップ">
  </div>
  <div class="exp1a-details">
    <p><strong>実験</strong><br>PODを78モードに固定し、Gaussian RBFのepsilon 5値×lambda 4値＝20条件を構築。validation 10ケースで評価。</p>
    <p><strong>横軸</strong>：Gaussian形状パラメータ ε<br><strong>縦軸</strong>：Ridge正則化パラメータ λ<br><strong>色・数値</strong>：validation 10ケースの平均L2ノルム誤差 [%]（小さいほど良い）</p>
    <div class="formula">φ(r) = exp[−(εr)²]<br>Φᵢⱼ = exp[−(ε‖μᵢ−μⱼ‖₂)²]<br>(Φ + λI)W = A</div>
    <p><strong>ε</strong>：小さいほど広く滑らかな基底、大きいほど局所的な基底。<br><strong>λ</strong>：係数の過大化を抑え、計算を安定化する正則化。</p>
    <p><strong>結果</strong><br><strong>赤枠</strong>の ε=0.5、λ=10⁻² が最小で、平均L2誤差は <strong>0.07367%</strong>。</p>

# 補足：Gaussian RBFによる温度場予測

<div class="rbf-supplement">
  <div>
    <h2>どうやって予測するか</h2>
    <p><strong>RBF</strong>は、入力間の距離だけで類似度を決める補間法。<strong>Gaussian</strong>は、距離 <em>r</em> に対して次の類似度を用いる。</p>
    <div class="formula">φ(r)=exp[−(εr)²]</div>
    <ol>
      <li>新しい密度マップ μ* と、80個のtrain入力 μⱼ の距離を計算</li>
      <li>距離に応じた重みで、78個のPOD係数 a(μ*) を予測</li>
      <li>POD基底 U を合成し、温度場を再構成</li>
    </ol>
    <div class="formula">(Φ+λI)W=A　［モデル構築］<br>a(μ*)=k(μ*)ᵀW　［係数予測］<br>Tᴿᴼᴹ(μ*)=T̄+Ua(μ*)　［温度場再構成］</div>
  </div>
  <div>
    <h2>パラメータを変えると</h2>
    <div class="parameter-card"><p><strong>ε：基底の広がり</strong><br>小さい → 広く滑らか。多くの入力を参照<br>大きい → 狭く局所的。近い入力を重視<br><span class="small">極端に小さいと差を表しにくく、大きいと入力間で不安定になりやすい。</span></p></div>
    <div class="parameter-card"><p><strong>λ：Ridge正則化</strong><br>小さい → モデル作成用データへ密着<br>大きい → 重みを抑え、安定・滑らか<br><span class="small">大きすぎると予測が平均化され、個別の変化を捉えにくい。</span></p></div>
    <p><strong>実験4</strong>では、εとλの組合せを変え、滑らかさとデータ適合のバランスを比較した。</p>
  </div>
