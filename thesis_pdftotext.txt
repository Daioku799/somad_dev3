概要

      半導体の集積による性能向上の限界に伴い、チップを垂直方向に積層する 3 次元集積回
     路（3D-IC）が次世代の集積技術として注目されている。しかし、高密度な積層構造は熱
     が蓄積しやすく、デバイスの動作速度低下や信頼性低下を引き起こす深刻な熱問題が実用
     化の大きな障壁となっている。
      これを解決するには各部品の配置・サイズ・物性値を設計パラメータとして熱設計を行
     う必要があり、特に IC 設計初期段階のパラメータが定めっていない段階では、高精度に
     素早くパラメータの決定を行う必要がある。その実現を目指して本研究では、有限体積法
     で用いる格子の生成法の実装と、設計パラメータの探索手法、探索を効率的に行うための
     次元縮約手法についての比較検討を行った。
      解析モデルおいては、形状タイプ・座標・サイズによって図形を簡単に表すプリミティ
     ブ表現を用いた。モデル生成では業界標準の GDSII 形式からチップと熱源形状を、JSON
     形式から TSV 配置と大きさ、各層の厚さ、物性値、熱源温度等の設計パラメータを読み
     込むハイブリッドな実装を行った。この実装では格子に対応する部品が一つに決まるので
     格子生成に失敗しない。
      次に、計算負荷を低減するため、固有直交分解（POD）と放射基底関数（RBF）を用
     いた非侵入型次数低減モデルを提案した。累積エネルギー寄与率（RIC）に基づく基底数
     の決定や、Incremental POD（IPOD）を用いた動的なモデル更新手法によって、解析精
     度を保持しつつ計算時間を激的に短縮することが期待できる。
      最適化フェーズにおいては、遺伝的アルゴリズム（GA）の進化プロセスを LLM の物
     理的知見に基づく推論によってサポートする「LLM-GA」を提案した。LLM が熱分布の
     結果を論理的に解釈し、従来の数学的、統計的手法では困難であった物理的妥当性の高い
     探索が期待できる。これに加え、外挿検知および誤差判定に基づく FVM のオンライン実
     行フローを構築し、ROM の予測信頼性を常に担保する適応的ワークフローを確立した。
      本研究により、高度な物理シミュレーションと LLM 推論能力を融合させた最適化基盤
     を提案した。提案手法は、3D-IC の熱設計における試行錯誤コストを削減し、開発期間の
     短縮に大きく貢献するものと期待される。

第1章

序論

1.1 研究の背景
 現代社会において身の回りにあふれるスマートフォン、車、家電などの電子機器の多くには半導体
が搭載されており、もはや半導体なしでは現代社会は成り立たなくなっている。特に情報機器に使わ
れる集積回路（IC）などのロジカル半導体については、長らくムーアの法則によって牽引されてきた
微細化によって、近年まで目覚ましい性能向上を遂げてきた。しかし、微細化のスケールが原子レベ
ルに近づくにつれ、トンネル効果をはじめとする量子力学的制約や、露光技術の物理的限界により、
従来の平面的なスケーリングによる進化は終焉を迎えつつある。このような背景から、次世代の集積
技術として、チップを垂直方向に積層する 3 次元集積回路（3D-IC）が注目されている。3D-IC は、
チップ間を Through-Silicon Via（TSV）等の垂直配線で接続することにより、配線長の短縮と実装
面積の劇的な削減を可能にする。しかし、積層化に伴う実装密度の向上は、単位体積あたりの発熱密
度の増大という深刻な熱問題を招いている。半導体素子におけるジュール熱の蓄積は、動作速度の低
下やリーク電流の増大を引き起こすだけでなく、IC の許容動作温度（一般に 70◦ C から 100◦ C 程
度）を超過し、物理的な破損や熱暴走を誘発する恐れがある。特に 3D-IC においては、積層構造内部
の熱が外部へ逃げにくい性質を持ち、従来の空冷技術のみでは熱管理が極めて困難である。さらに、
異種材料間の熱膨張係数の差に起因する熱応力は、TSV 周辺のクラックや剥離といった構造的欠陥
を招く。したがって、3D-IC の実用化に向けては、最高温度の抑制のみならず、温度分布に起因する
信頼性評価を含めた多角的な熱設計最適化が喫緊の課題となっている。



1.2 研究の目的
 半導体製品の開発プロセスは多岐にわたり、設計の進行度に応じて要求されるシミュレーションの
性質が変化する。開発後期においては詳細な解析に基づく最終確認が行われるが、製品の付加価値
を決定づけ、開発効率を左右するのは設計初期段階における意思決定（フロントローディング）で
ある。しかし、設計初期段階では、各部品の配置や構造パラメータ（層の厚さ、物性値、発熱量）が
未確定であり、設計空間を網羅的に探索する必要がある。この段階で有限体積法（FVM）等のフル
オーダーモデル（FOM）による高精度解析を繰り返すことは、膨大な計算時間を要するため現実的
ではない。本研究の目的は、設計初期段階において、設計者が入力する制約条件に基づき、効率的な
第1章   序論                                          2

熱構造となるように層の厚さや TSV 配置等の設計パラメータを高速かつ自動的に最適化・予測する
技術を検討し、提案することにある。これにより、3D-IC の熱設計における試行錯誤コストの削減
と、開発期間の短縮に貢献するシステムの開発につなげる。

第2章

従来研究の分析と課題

2.1 3D-IC の熱性能最適化の現状と課題
 IC のさらなる高集積化を実現するため、3D-IC の設計開発が盛んに行われている。しかし、積層
化に伴う熱密度の増大は集積化における大きな障壁となっており、この問題を解決するために、デバ
イスの構造的側面から放熱効率を最大化する様々なアプローチが試みられている。
 3D-IC は、その構造特性上、2D-IC と比較して熱が内部に蓄積されやすいことが指摘されている
[1]。特に、層間を電気的に接続する Through-Silicon Via（TSV）やはんだバンプは、同時に垂直方
向の主要な熱伝導経路（サーマルビア）としても機能するため、これらの配置や密度はチップ全体の
温度分布に極めて大きな影響を与える [2]。そのため、効果的な熱管理を実現するには、TSV 配置や
層構造を対象とした高度な設計パラメータ最適化が必要不可欠であり、本研究ではこの設計パラメー
タ最適化による熱問題の解決を目指す。
 これまでの研究では、複雑な設計空間から最適解を導出するために、生物の進化プロセスを模した
遺伝的アルゴリズム（Genetic Algorithm, GA）[3] や粒子群最適化（Particle Swarm Optimization,
PSO）[4] などの進化計算や、共分散行列の学習により実数値最適化を行う（Covariance Matrix
Adaptation Evolution Strategy, CMA-ES）[5] などの、様々な手法によって設計パラメータ探索と
最適化が行われてきた。しかし、3D-IC の精密な熱評価には有限体積法（Finite Volume Method,
FVM）等の計算負荷の高い数値解析が必要であり、最適化プロセスにおける膨大な試行に対して、
これらの高精度解析を何度も実行することは、計算時間の観点から現実的ではない。
 この計算コスト削減に向けた取り組みとして、いくつかの有力なアプローチが提案されている。一
つは、解析モデルを簡略化した熱抵抗ネットワークモデルを用いる手法である [6]。また、材料密度
を連続変数として扱う均質化法などを基に最適な位相構造を導き出すトポロジー最適化を熱問題に
適用する試みもなされている [7]。しかし、熱抵抗ネットワークは計算が高速である反面、局所的な
温度分布（ホットスポット）の再現性に課題があり、トポロジー最適化は設計自由度が高い一方で、
3D-IC のような多層かつ異種材料が混在する複雑な境界条件の下では、収束性や製造制約の考慮が困
難になる場合が多い。
 これに対して有力な代替手法として広く検討されているのが、次数低減モデル（Reduced-Order
Model, ROM）の活用である [8]。ROM は、事前に収集した高精度解析データ（スナップショット）
に基づき、低次元基底で構成される近似空間上で温度場を評価する。これにより、FVM と同等の物
第2章   従来研究の分析と課題                                   4

理的妥当性を保持しつつ、計算負荷を劇的に低減できるという利点がある。本研究において ROM ア
プローチを採用する理由は、この「高精度」と「低コスト」の両立が、繰り返しの試行を要する構造
最適化において極めて有効だからである。
 しかし、これらの方針においても依然として以下の課題が残っている。
 第一に、ROM 構築における効率性の課題である。精度の高い ROM を構築するには、設計空間を
適切に代表するスナップショットの収集が不可欠である。しかし、探索すべきパラメータ範囲が広大
かつ複雑な場合、どのデータ点が精度向上に寄与するかを事前に判断することは困難であり、結果と
してスナップショット生成のための膨大な事前計算がボトルネックとなる。
 第二に、パラメータ探索手法そのものの非効率性である。従来の最適化手法は、あくまで数値的・
統計的な試行錯誤に依存しており、「熱源の近傍に高熱伝導体（TSV）を配置すべきである」といっ
た物理的な因果関係や設計者の知識を探索に直接反映することができない。そのため、物理的に明ら
かに不適切な個体を多数評価してしまい、収束までに多大な時間を要するという課題がある。
 本研究ではこれらの問題を基に、3D-IC の熱性能最適化において適切な手法を比較検討していく。

第3章

熱解析の基礎方程式と各種条件

3.1 基礎方程式
 熱の移動は温度勾配によって生じ、その移動量は以下のフーリエの法則（3.1）によって記述さ
れる。
                                         q = −λ∇T                                           (3.1)

ここで、q は単位面積・単位時間あたりの熱移動量である熱流束 [W/m2 ]、λ は熱伝導率 [W/(m·K)]、
T は温度 [K] を表す。
 物質中における伝熱形態は、固体中を伝わる熱伝導と、固体と液体の界面での熱移動である熱伝達
と、電磁波等によって熱が伝わる熱輻射の３つの形態に大別される。まず、熱伝導方程式は熱流束お
よびエネルギー保存則によって記述される。微小空間において、単位時間あたりに外部から流入する
熱量と内部で発生する熱量の和は、外部へ流出する熱量と内部エネルギーの変化量の和に等しい。密
度を ρ [kg/m3 ]、比熱を c [J/(kg·K)]、単位体積あたりの発熱量を Q [W/m3 ] とすると、一般的な
熱伝導方程式は式（3.2）で示される。
                   ∂T
                       = ∇ · (λ∇T ) + Q
                               ρc            (3.2)
                    ∂t
 熱伝導率 λ に関して、一般的な熱伝導問題としては温度 T の関数となるため非線形問題であり、
また熱が伝わる方向によって熱伝導率が変化する異方性がある。特に半導体モデルでは、配線や絶縁
層の配置と多層性に起因して面内方向と縦方向に異なる熱伝導特性が現れるため、本研究ではそれぞ
れの方向に異なる熱伝導率を与えて考える。
 よって、式（3.2）を３次元直交座標について展開すると、次式 3.3 のように表される。
                         (           )          (           )          (           )
               ∂T   ∂           ∂T         ∂           ∂T         ∂           ∂T
            ρc    =          λx          +          λy          +          λz          +Q   (3.3)
               ∂t   ∂x          ∂x         ∂y          ∂y         ∂z          ∂z
 次に、熱伝達について述べる。熱伝達は、固体表面の熱伝導と流体による輸送（対流）が複合した
現象である。重力の影響下で高温部付近の流体が浮力により上昇する現象を自然対流と呼び、外部か
らのファン等の動力によって強制的に流体を動かす現象を強制対流と呼ぶ。本研究で使用するモデ
ルのヒートシンクは、強制対流による冷却を想定している。固体表面から流体へ輸送される熱流束 q
は、ニュートンの冷却法則に基づき、以下の式（3.4）で定義される。

                                     q = h(Ts − T∞ )                                        (3.4)

ここで、h は熱伝達係数 [W/(m2 ·K)]、Ts は固体表面温度、Tf は流体の代表温度である。
 また、熱の移動は物質を媒介しない空間においても発生する。電磁波や光がエネルギーを輸送し、
熱を伝える現象を熱放射と呼ぶ。熱放射による熱流束の大きさは、次式（3.5）のように表される。

                               q = εσT 4                  (3.5)

ただし、ε は輻射率、σ [W/(m2 K 4 )] はステファン-ボルツマン定数である。輻射率は 0 ≤ ϵ ≤ 1 の範
囲を取り、理想的な放射体である黒体に比べて物体がどれくらいエネルギーを放出するかを表す。本
研究の解析モデルにおいては、熱伝導および熱伝達による熱移動の寄与が支配的である。そのため、
熱放射による影響については無視できる。


3.2 離散化手法
 本研究では、空間離散化手法として有限体積法（Finite Volume Method, FVM）を用いる。FVM
は流体解析や熱伝導解析において広く採用されている数値解法であり、各計算セルにおいて積分型の
保存則が厳密に満足される点が大きな特長である。本手法では、計算領域をコントロールボリューム
（CV）と呼ばれる微小体積に分割し、各 CV に対して定義された積分型のエネルギー保存則を評価す
ることで、領域全体での物理的な保存性を担保する。また、本研究では設定されたモデルの最終的な
温度場を評価するので、定常問題を考える。3 次元空間におけるあるセル P とその隣接セル（East,

3.3 解析モデル
 本解析で用いる 3D-IC モデル（図 3.4、3.5）の構造について述べる。本モデルは、3 層のシリコン

線基板（PCB substrate）が接合されている。各シリコンチップ層を垂直方向に貫通し、層間の電気
的・熱的接続を確保するように TSV（Through-Silicon Via）が配置される。各チップ層の TSV 間
は、はんだバンプ（Solder Bump）によって物理的に接続される構成となっている。
 各部品は、複雑な細部を省いても、熱伝導に寄与する主要な断面積と体積を維持していれば、マク
ロな温度分布に与える影響は無視できるほど小さくなる。これに基づき本研究でのモデルは、単純な
直方体、球体、円柱によるプリミティブ表現で構成され、その形状データは、形状タイプと座標と大
きさによる最低限の量のパラメータで表現される。このプリミティブ表現と外部ファイルによるモデ
リングの組み合わせによって、TSV の位置や本数、層構造といった設計変数をプログラム外から容

デルを即座に再構成したり、TSV 同士の距離制限やチップ範囲などの物理的制約を単純な数式とし
て記述でき、最適化のパラメータとして利用しやすくなる。さらに、幾何形状を数学的に厳密なプリ
ミティブとして定義することで、複雑な実設計データに起因する境界の不確定性や隙間を排除してい
る。これにより、格子点がどの部品包含されているかを一意に決定できるため、設計パラメータを大
幅に変更する最適化プロセスにおいても、格子生成に失敗することのない安定したマッピングが可能

第4章

次数低減モデルの構築

 3D-IC の構造最適化問題においては、広大なパラメータ空間を探索するために膨大な回数の数値計
算が必要となる。これら全てのケースに対して有限体積法（FVM）を適用することは、高精度な解
析を可能にする一方で、極めて大きな計算コストを要し、現実的な時間内での最適化を困難にする。
これに対し、次数低減モデル（Reduced Order Model, ROM）は、フルオーダーモデルから温度場
の支配的な空間基底を抽出することで、物理的特徴を保持したまま、極めて少ない次元数で温度場を
近似することができる。

4.2 次元低減手法の比較
 ROM の構築において極めて重要な過程である次元低減には、複数のアプローチが存在する。本節
では、熱伝導問題の解析において広く用いられる 2 つの代表的な手法について比較検討を行う。

固有直交分解（POD） 固有直交分解（Proper Orthogonal Decomposition, POD）は、スナップ
    ショット行列に対して特異値分解（Singular Value Decomposition, SVD）を適用し、抽出さ
    れた空間基底を用いる手法である。スナップショット行列 X ∈ RM ×S の SVD は次のように
    定義される。
                                                  X = U ΣV T                                   (4.10)

    ここで、U ∈ RM ×M および V ∈ RS×S は直交行列であり、Σ ∈ RM ×S は対角成分に特異値
    σi を持つ対角行列である。SVD によって得られた空間基底（左特異ベクトル）のうち、特異
第4章   次数低減モデルの構築                                                                         15

    値の大きい順に r 本の基底を選択することで、低次元空間を構成する基底ベクトル群が得ら
    れる。特異値の大きさは、その基底が空間全体の変動を表現する際の「寄与度」に対応してお
    り、上位のモードほど支配的な物理現象を表している。こうして構築される低次元空間は、最
    小二乗誤差の意味において元の空間を最も適切に近似する基底であることが、Eckart–Young
    の定理によって数学的に保証されている。
テンソルトレイン（TT）分解 一方、テンソルトレイン（Tensor Train, TT）分解は、スナップ
    ショットデータを多次元配列（高階テンソル） A ∈ Rn1 ×n2 ×···×nd として扱い、この配列を
    複数のテンソルコアの積によって近似する手法である [20]。
    TT 分解は次式で表される。

                   A(i1 , i2 , . . . , id ) ≈ G1 (i1 )G2 (i2 ) . . . Gd (id )   (4.11)

    TT 分解の主な特徴は、空間方向ごとの多次元構造を保持したまま圧縮が可能であり、変数の
    増加に伴う計算コストの爆発、いわゆる「次元の呪い」を効果的に回避できる点にある。しか
    し、POD と比較して、抽出されたコアから物理的な空間モードを直接的に解釈することが困
    難であるという側面を持つ。

 本研究では以下の理由から POD を採用する。

  1. 物理的解釈性: POD 基底は空間的な温度分布パターンとして視覚化が可能であり、物理的特
    徴を捉えやすい。
  2. 拡張性: 最適化の過程で外挿領域や誤差の大きな領域が検知された際、新規スナップショット
    を既存の行列に追加して再構築を行う適応的更新が容易である。
  3. 実装の容易性: TT 分解と比較して、SVD に基づくアルゴリズムは汎用ライブラリが非常に充
    実しており、確実な実装が可能である。
  4. 計算規模の妥当性: 本研究で扱う設計パラメータの数（300 サンプル程度）は、POD におい
    て次元の呪いが致命的となるほど高次元ではない。



4.3 累積エネルギー寄与率（RIC）による基底数の決定
 SVD によって抽出された空間基底から低次元基底を構成する際、近似空間の次元数（ランク）r を

4.5 ROM の更新

第5章

オンライン計算

 前章で述べた ROM 構築は、パラメータ探索が始まる前の事前準備であり、最適化ループとは切り
離されていることからオフライン計算と呼ばれる。本章で述べるオンライン計算は、オフライン計算
で得られた近似モデルを基に高速に進化計算のループを実行する工程である。ROM を導入すること
でパラメータ探索をするごとに FOM の計算をする手間を省き、効率的に探索を行うことができる。
 本章では、まずオンライン計算で用いるパラメータ探索手法について比較検討後、決定した探索手
法についての要素技術や定義を述べ、最後に全体の流れをまとめる。



5.1 パラメータ探索手法
 パラメータ探索（最適化）アルゴリズムには、問題の性質に応じて多様な手法が存在する。本研究
の対象である 3D-IC の熱設計最適化に適用可能な主要手法には以下のようなものがある。

  • 遺伝的アルゴリズム（Genetic Algorithm, GA）
   生物の進化過程（選択、交叉、突然変異）を模倣した確率的探索手法である。評価関数の値に
   基づく個体の選別と、パラメータ同士の情報の組み換えによって探索を進める。多峰性を持つ
   複雑な設計空間においても、局所解に陥ることなく全域的な最適解を探索できる能力に優れて
   いる。その一方で、解から離れた領域を探索することで計算時間が長くなる欠点もある。
  • ベイズ最適化（Bayesian Optimization,BO）
   ガウス過程回帰などのサロゲートモデルを用い、未知の領域に対する期待改善量を最大化する
   ように次の探索点を決定する手法である。高コストな評価関数に対して少ない試行回数で収束
   する利点があるが、パラメータの次元数が増加するにつれて代理モデルの構築コストが指数関
   数的に増大する課題がある。
  • 遺伝的プログラミング (Genetic Programming, GP)
   個体をビット列や数値ではなく「木構造（計算式やプログラム）」として表現し進化させる手
   法である。物理現象を記述する近似式の自動生成などに用いられるが、本研究のように具体的
   な幾何学的配置（座標や直径）を直接最適化する問題においては、解の表現が複雑になりすぎ
   る傾向がある。
  • CMA-ES
第5章   オンライン計算                                                              20

   共分散行列適応進化戦略 (Covariance Matrix Adaptation Evolution Strategy, CMA-ES)
   は、探索を進めながら、評価が改善される方向の相関関係（共分散行列）を学習する。また、
   探索の歩幅を自動調節するので、大胆な探索と最後の微調整を両立できる。

 本研究では、有限体積法（FVM）により離散化された熱伝導方程式を扱い、設計パラメータには
TSV の座標や直径といった物理量が含まれ、これらは設計空間において強い非線形な応答を示す。
この前提を基に各手法を比較する。
 まず、ベイズ最適化はフルオーダーモデル（FOM）のように一回の評価が極めて重い場合には有
効であるが、本研究のように次数低減モデル（ROM）を用いて評価コストを劇的に低減した環境下
では、代理モデル構築のオーバーヘッドがメリットを上回り、採用する意義が薄い。次に CMA-ES
は、連続的な勾配情報を利用して高精度な収束を実現するが、本解析のようなメッシュ解像度に依存
する系においては、メッシュ内の微小な変化に対して評価値が変化しない「不感帯」で探索が停滞
し、局所解や不適切な解に収束するリスクがある。
 これに対し、GA は不連続な評価関数に対してもロバストに動作するが、探索が確率的なランダム
性に依存するため、物理的に無意味な領域（熱源から遠い箇所の探索など）を評価し続けるといった
「探索の収束の遅さ」が最大の欠点となる。
 そこで本研究では、この GA の非効率性を大規模言語モデル（LLM）の導入によって解決する手
法を提案する [10]。LLM が持つ物理的なドメイン知識を探索プロセスに介入させることで、従来の
数学的・確率的アプローチのみでは不可能であった「物理的意味を加味した探索誘導」を実現する。
具体的には、LLM が熱分布の結果を解釈し、物理的妥当性の高い方向へ突然変異や初期集団の生成
を誘導することで、探索空間を効果的に絞り込む。



5.2 LLM-GA
 本研究では、大規模言語モデル（LLM）の物理的な知識による推論能力を進化計算（GA）の各オ
ペレーターに統合した「LLM-GA」の構築を提案する。先行研究 [10] によれば、LLM は複雑な構造
を持つ組合せ最適化問題において、単なる解の生成器としてだけでなく、進化的オペレーターとして
機能し、問題の制約を遵守しながら解を反復的に改善する能力を持つことが示されている。本研究の
新規性は、従来の GA が依存していた純粋に統計的・確率的な探索プロセスに対し、LLM が保持す
る熱流体解析のドメイン知識を介入させることで、物理的因果関係に基づいた探索誘導を実現した点
にある 。

  • 交叉
   交叉工程では、優れた評価を持つ親個体群のパラメータセットを LLM に入力する。LLM は
   親個体間の共通点や相違点を抽出し、それらを論理的に結合することで、単なる統計的な組み
   合わせ（平均値や一点交叉など）では到達しにくい、物理的な因果関係を維持した子個体を生
   成する。
  • 適応的変異
   変異は解の多様性を維持するために不可欠であるが、完全なランダム変異は収束を妨げる。本
第5章   オンライン計算                                              21

   手法では、LLM が現在の解において排熱が滞っている領域を特定し、その近傍へ優先的に
   TSV を再配置する「適応的変異」を導入する。LLM が現状の解における温度分布を解釈し、
   排熱が滞っているホットスポット領域を特定する。特定された領域の近傍へ優先的に TSV を
   再配置、あるいは直径を調整するよう LLM が指示を生成する。これにより、従来のガウス変
   異と比較して、物理的妥当性の高い探索空間への集中が可能となる。
  • 選択
   選択工程では、目的関数の評価値に加え、LLM による解の背後にある構造的な妥当性や論理
   的な整合性の評価を補助的に用いる。特に、熱的な改善が頭打ちになった際、LLM が進化的
   プロセスにおける解の停滞を検知し、多様性を促す個体を戦略的に次世代へ残すことで、局所
   解からの脱却を図る。
  • エラー修正機構 LLM の出力には稀に制約条件（TSV 同士の干渉やチップ範囲外への配置な
   ど）を無視したり、フォーマット上のエラーを起こす不確実性が含まれる。そこで、先行研究
   [10] の知見に基づき、LLM の出力後に物理的制約を確認する検証層を設け、制約違反がある
   場合には自動的にパラメータを修正する機構を実装する。これにより、LLM の柔軟な探索能
   力と、工学的な厳密性を両立させる。

 次に、本研究で用いる各手法の説明と定義を行う。


5.3 評価関数と最適解の決定
 ROM によって算出された近似温度場 TROM (x; µi ) を、設計目的に基づいて定量的指標で評価す
る。IC の正常な動作を保証する観点からはチップ内の最大温度が、また熱応力による構造破損を抑
制する観点からは最大温度勾配や熱源間の温度差などが評価項目として挙げられる。また、電気的な
遅延を減らすために TSV の配線長を最小化することも多い。
 本研究では、提案手法の基本的な妥当性を検証するため、パラメータを TSV 配置、評価関数を
チップ全体の最大温度を単一の対物指標として用いることを提案する。
 評価関数 f (µ) は次式で定義される。

                    f (µ) = max TROM (x, µ)        (5.1)
                           x∈Ω

ここで、Ω は解析対象とする 3D-IC の全領域を指す。最適化のプロセスにおいては、この評価関数
f (µ) を最小化する設計パラメータ µ の探索を目的とする。
 最適解の決定方法として、最良固体が一定世代（ストール世代数）更新されない場合と、改善幅の
閾値が小さい場合に進化計算を停止をする条件を設け、進化計算が停止した段階での最優良固体を最
適解として決定する [22]。ストール世代数については全体の世代数の 10 ∼ 20% の世代数、改善幅の
閾値については目的関数の 10−4 〜10−6 程度を目安とする。


5.4 外挿検知と ROM 更新
 既存のスナップショット群が覆う凸包（Convex Hull）の外部や、サンプル点が極めて疎な領域を
「外挿領域」と呼ぶ。この範囲では ROM の精度が保証されないので、外挿となったパラメータに対
第5章   オンライン計算                                                    22

して FOM の計算を行い、ROM を更新する必要がある。ROM 更新の方法については 4.5 で述べた。
 本研究では、LHS のサンプリング密度に基づき外挿判定を行う [23]。
 具体的には、判定する新たなパラメータ µ(∗) と、その最も近くにある既知のスナップショット点
µ(j) との距離 d(µ∗ ) を用いる。パラメータ空間での各次元はスケールが異なるので、各パラメータ
を正規化する。
 あるパラメータの正規化を次式（5.2）で表す。

                                   µi − µmin
                          µ′i =          i
                                                         (5.2)
                                  µmax
                                   i   − µmin
                                           i

 この操作を各次元について施すと、距離 d(µ∗ ) は次式で表される。

                   d(µ(∗) ) =     min |µ′(∗) − µ′(j) |   (5.3)
                                j=1,...,N


 算出された最小距離 d(µ(∗) ) があらかじめ設定された閾値 dcrit を上回る場合、当該パラメータを
外挿と判定する。初期スナップショット群において、各点から最も近い点までの距離（の平均 davg
を計算し、その 1.5 倍〜2.0 倍 程度を dcrit と設定する。外挿と判定されたパラメータに関しては、
直ちに FVM による高精度解析を実行し、得られた結果を新たなスナップショットとして行列 S に
追加する。その後、SVD による基底の再抽出および RBF モデルの再学習を行うことで、ROM の空
間表現能力を動的に拡張する。



5.5 誤差判定に基づく FVM の実行と ROM 更新
 最適化プロセスにおいて評価関数に基づき「有望」と判断された個体（エリート個体等）について
は、その信頼性を担保するために FVM による検証を行い、誤差が大きい場合は ROM 更新を行う。
ROM 更新の手法については 4.5 で述べた。ROM による予測温度場 TROM と、FVM による厳密
解 TF V M との誤差を評価し、近似モデルの妥当性を確認する。誤差の指標として、本研究では以下
の最大絶対誤差を用いる。
                 ϵmax =     max |TROM,k − TF V M,k |     (5.4)
                          k=1,...,M

算出された誤差 ϵmax が許容値 ϵtol 以下であれば、当該パラメータにおける ROM の予測は十分に
信頼できるものと判断し、探索を継続する。一方で、誤差が許容値を超える場合は、現在の ROM の
空間表現能力が当該領域において不十分であると見なし、得られた FVM 結果をスナップショット行
列に追加して ROM を再構築する。この逐次更新プロセスにより、最適解近傍におけるモデル精度を
重点的に向上させることが可能となる。



5.6 ワークフロー
 最後に、本研究で提案するオンライン計算のワークフローを次に示す。

  1. パラメータの生成
   遺伝的アルゴリズム（GA）に基づき、現世代の個体群（設計変数 µ の集合）を生成する。
第5章   オンライン計算                                        23

 2. 外挿検知および適応的更新
  生成されたパラメータが、既存のスナップショット群が構成する凸包（Convex Hull）の外側、
  すなわち ROM の精度が保証されない「外挿領域」にあるか否かを判定する。外挿と判定され
  た場合には、直ちに FVM を実行し、得られた結果をスナップショット行列に追加して ROM
  を再構築（更新）する。
 3. ROM による高速評価
  ROM を用いて各個体の温度場を瞬時に予測し、5.3 の評価関数を基にパラメータを評価する。
 4. FVM による誤差検証と逐次更新
  最適化プロセスにおいて有望と判断された個体に対し、検証用の FVM を実行する。ROM に
  よる予測値と FVM による厳密値の誤差が許容値 ϵ を超える場合、当該サンプルをスナップ
  ショットに追加し、POD 基底とモーダル係数の再計算を行うことでモデルの再構築を行う。
 5. 次世代の生成
  評価結果に基づき、交叉・突然変異を経て次世代のパラメータ群を生成する。以上のプロセス
  を 5.3 で示す停止条件を満たすまで繰り返す。

第6章

結論

6.1 本研究のまとめ
 本研究の目的は、次世代の半導体技術である 3D-IC の熱設計において、高精度な物理解析と低減
された計算コストを両立させた最適熱設計のアプローチを提案することにある。この目的を達成する
ため、本研究では解析モデルの構築、次数低減モデル（ROM）の適用、および LLM を融合させた
最適化アルゴリズムの 3 つの観点から検討を行い、以下の結論を得た。
 モデル構築に当たっては形状タイプ・座標・サイズといった単純な情報によって表現されるプリミ
ティブ表現によってモデル形状を与えることで、数値データを変更するだけで容易に設計を変更でき
たり、設計上の制約条件を単純な数式で表せるなどの、パラメータ探索に有利な実装を行うことがで
きた。また、GDSII フォーマットに基づくシリコン層と熱源の形状に対しては、Ray Casting 法とに
よる幾何学的包含判定を導入することで、計算格子への高精度かつ高速なマッピングを可能とした 。
 4 では、次元低減手法とモーダル係数予測モデルの比較検討を行い、固有直交分解（POD）と放射
基底関数（RBF）を用いた非侵入型次数低減モデルが最適であると判断した。基底本数の決定法につ
いて累積エネルギー寄与率による決定を検討したり、ROM 更新においては ISVD を用いたメモリリ
ソースを抑えつつモデルの空間表現能力を動的に拡張する逐次更新手法を導入することで、、最適な
モデル構築を考案できた。
 5 のパラメータ探索手法の検討では、大規模言語モデル（LLM）を遺伝的アルゴリズム（GA）の
進化的操作に組み込んだ手法が最適であるという結論に至った。この手法では、従来の数学的、統計
的な探索手法では困難であった「熱源付近への優先的な TSV 配置」といった物理的な知見を考慮し
た探索が可能である。さらに、外挿検知機能とシミュレーションのオンライン実行を組み合わせるこ
とで、ROM の予測精度を動的に保証する適応的なワークフローを考案することもできた。
 以上の通り、本研究は、高度な物理シミュレーション技術と最新の AI 技術を融合させることによ
り、複雑な 3D-IC の熱設計空間における高速かつインテリジェントな最適化基盤を提示したもので
ある。
第6章   結論                                            25



6.2 今後の課題と展望
 本研究の評価関数はチップ全体の最大温度の最小化に限定したが 、実際の 3D-IC 設計では、熱応
力に起因する構造的信頼性や、TSV 配置による配線遅延（RC 遅延）、および製造コストの最小化な
ど、複数の指標が互いにトレードオフの関係にある。今後は、これらを同時に考慮可能な多目的最適
化アルゴリズムへの拡張が必要である。
 また、本研究で扱ったパラメータ数では POD による次元低減が有効であったが 、さらに格子数や
設計パラメータ数が増大した超多次元の設計空間においては、次元の呪いを回避するためのサンプリ
ング手法のさらなる高度化や、4.2 で述べられた TT 分解等の手法のさらなる検討が求められるが、
TT 分解への LLM 導入は物理的なモードが読み解きづらいことから課題も多い。
